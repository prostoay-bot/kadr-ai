# Кадровый помощник — KADR AI

Веб-приложение в тестовой разработке: **Кадровый аудитор**, **Кадровый радар**, поиск по статьям ТК РФ.

## Текущее состояние GitHub
- `index.html` — веб-интерфейс приложения.
- `data/tk-rf.json` — пользовательский корпус ТК РФ (официальная актуальность не подтверждена).
- `vendor/pdfjs/pdf.mjs`, `vendor/pdfjs/pdf.worker.mjs` — модули обработки PDF.
- GitHub Pages настраивается отдельно в **Settings → Pages**; само наличие кода не означает, что сайт опубликован.

## Важные ограничения
1. Это прототип, **не** полноценная юридическая экспертиза и **не** готовый сервис для персональных данных.
2. Редакция ТК РФ в базе предположительная и требует сверки с официальными источниками.
3. Проверка DOCX, русскоязычного OCR, PDF и сценариев аудита в браузере не завершена.
4. Правила могут пропускать нарушения и давать ложные предупреждения.
5. Не загружайте реальные трудовые договоры или другие документы с персональными данными.

## Как пользоваться
После включения GitHub Pages приложение будет доступно по адресу
`https://prostoay-bot.github.io/kadr-ai/`.

Для локального запуска из папки проекта можно использовать `python3 -m http.server 8000`, затем открыть `http://localhost:8000/`.
