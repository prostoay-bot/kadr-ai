# Кадровый помощник — собранный проект

Это **тестовая версия**, не юридическое заключение и не система для реальных персональных данных.

## Состав
- `index.html` — веб-приложение с двумя модулями и поиском законодательства.
- `data/tk-rf.json` — корпус статей ТК РФ, собранный из пользовательского RTF. Дата редакции **предположительная** и официально не сверена; это не автоматически актуализируемый источник.
- `vendor/pdfjs/pdf.mjs` и `vendor/pdfjs/pdf.worker.mjs` — локальная библиотека обработки текстовых PDF.
- `tools/build_corpus.py` — сборщик корпуса из txt/docx/pdf/html; для RTF сначала конвертируйте в TXT (например, pandoc).
- `tools/vendor.sh` — сценарий получения дополнительных OCR-библиотек при наличии сети, не выполнялся.
- `tests/` — ранее переданный разработчиком набор тестов, а не подтверждение их успешного прохождения в нашей среде.
- `test-files/` — искусственные учебные файлы.

## Как открыть
Из папки проекта запустите `python3 -m http.server 8000` и откройте `http://localhost:8000`.
Простое открытие `index.html` как `file://` не подгрузит `data/tk-rf.json` из-за защиты браузера.

## Известные ограничения
1. Браузерные тесты в текущей среде заблокированы (ERR_BLOCKED_BY_ADMINISTRATOR для localhost). Скрипт JavaScript проверен `node --check`, Python-файлы скомпилированы.
2. Реальный русский OCR фотографий и сканов не протестирован; Tesseract.js и русский языковой пакет не входят в архив.
3. DOCX реализован встроенным парсером; сложные форматирования и нестандартные DOCX требуют проверки.
4. Правила проверяют только заранее заданные случаи. Они не понимают любые правовые нюансы и не являются полноценной юридической экспертизой.
5. Нет надёжной автоматической актуализации законодательства и защиты персональных данных.
6. Отчёт `REPORT_AUTO.md` получен от другого разработчика; указанные в нём ошибки не признаны исправленными автоматически.
