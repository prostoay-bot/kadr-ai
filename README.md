# KADR AI — Кадровый помощник

**Адрес опубликованной тестовой версии:** https://prostoay-bot.github.io/kadr-ai/

Кадровый аудитор, Кадровый радар, поиск статей ТК РФ. Бесплатное браузерное приложение, исходный код в этом репозитории.

## Статус передачи заказчику

**Тестовая версия. Не допущена к обработке настоящих персональных данных сотрудников.**

Релиз допускается к показу на вымышленных или надёжно обезличенных документах. Перед промышленным использованием необходимы:
- успешный актуальный end-to-end прогон (TXT, DOCX, PDF, OCR, Радар, импорт/экспорт, мобильный экран);
- ручная сверка юридических правил и полного текста ТК РФ с официальной редакцией на дату события;
- независимая проверка безопасности, сетевых запросов, внешних библиотек и соблюдения законодательства о персональных данных;
- приёмка заказчиком по согласованным критериям.

**Не выдавать тестовую версию за юридическую экспертизу.** Отсутствие замечаний не доказывает отсутствие нарушений.

## Проверки

GitHub Actions → [список рабочих процессов](https://github.com/prostoay-bot/kadr-ai/actions):
- `Static release gates` — синтаксис скриптов, совместимость PDF.js, метаданные правового корпуса, проверки безопасности;
- `KADR AI browser release checks` — загрузка TXT/DOCX/PDF, интерфейс, мобильная верстка;
- `OCR safety regression tests` — контроль качества отдельных страниц.

Сценарий проверки должен быть **зелёным в GitHub Actions**. Наличие сценария или сохранение кода не означает, что он успешно выполнился.

## Файлы

- `index.html` — клиентское приложение.
- `data/tk-rf.json` — ТК РФ, импортированный из пользовательского документа. **Редакция/содержание не сверены постатейно**.
- `vendor/pdfjs/pdf.mjs`, `vendor/pdfjs/pdf.worker.mjs` — обработка PDF, версия 5.6.205.
- `tests/` — контрольные тесты.
- `tools/` — утилиты подготовки правовой базы и зависимостей.

## Безопасность и данные

Аудит текста выполняется в браузере; некоторые сторонние модули могут подгружаться из CDN. Данные задач и реестра замечаний сохраняются в `localStorage`, без полноценной системы контроля доступа, шифрования и разграничения пользователей. Проверка формата персональных идентификаторов не может обеспечить обезличивание документа.

**Не загружайте паспортные данные, СНИЛС и любые другие персональные данные реальных работников.** Создавайте тестовые документы с вымышленными сведениями.

## Запуск

После публикации GitHub Pages: https://prostoay-bot.github.io/kadr-ai/

Локально: `python3 -m http.server 8000` из корня репозитория, затем `http://localhost:8000/`.

## Известные ограничения

- Старый формат Word `.doc` не поддерживается: преобразуйте копию в `.docx` или PDF.
- OCR может требовать интернета и дополнительных библиотек. Качество зависит от исходного изображения.
- Сканированные страницы могут требовать ручного сопоставления с оригиналом.
- Правовые выводы эвристические, проверка законодательства по каждой статье не завершена.
- История задач хранится локально и может исчезнуть при очистке браузера. Экспортируйте резервные копии.
